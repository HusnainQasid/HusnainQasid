## Setup Notes

<details>
<summary><strong>1. Add your real photo (optional)</strong></summary>
<br>

The character panel in the banner and the lanyard badge currently show a
stylized placeholder "hologram" avatar — no photo was provided when this
repo was generated, so nothing was invented in its place.

To drop in your own photo:

```bash
pip install pillow --break-system-packages
python3 scripts/embed_avatar.py path/to/your-photo.png
```

This crops it, makes the background transparent, and embeds it as base64
directly into `assets/banner.svg`, `assets/banner-light.svg`, and
`assets/lanyard.svg` — no external image host, so it can't ever go missing.
Works best with a fairly clean/solid background; see the comments at the
top of the script for details.

</details>

<details>
<summary><strong>2. Turn on the snake animation</strong></summary>
<br>

The snake workflow needs somewhere to publish its output the first time:

1. Push this repo to `github.com/HusnainQasid/HusnainQasid` (the special
   repo name that GitHub uses as your profile README).
2. Go to **Settings → Actions → General → Workflow permissions** and enable
   **"Read and write permissions"** (the workflow needs this to push to the
   `output` branch).
3. Run the workflow once manually from the **Actions** tab
   (`Generate Snake Animation` → *Run workflow*), or just wait for the daily
   scheduled run.
4. After the first run, an `output` branch will exist with
   `github-snake.svg` / `github-snake-dark.svg` — the README already points
   at it.

</details>

<details>
<summary><strong>3. Update the placeholder numbers</strong></summary>
<br>

`assets/stats.svg`, `assets/langs.svg`, and `assets/trophies.svg` are fully
local (no external stats service, so they never break or rate-limit) — which
also means their numbers are placeholders. Open the corresponding generator
in the repo history or hand-edit the `<text>` values directly in the SVGs to
match your real stats.

</details>

<details>
<summary><strong>4. Cache-busting</strong></summary>
<br>

Every local asset is referenced with a `?v=1` query string. If you edit an
SVG and GitHub/your browser is still showing the old cached version, bump
it to `?v=2`, `?v=3`, etc.

</details>
